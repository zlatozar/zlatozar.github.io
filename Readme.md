# Zlatozar Zhelyazkov — Blog

Personal engineering blog built with Jekyll and hosted on GitHub Pages.

## Local Preview (`just` / Docker)

To build and preview the site locally with auto-regeneration:

```bash
just preview
```

(Or directly via Docker Compose: `docker compose up --build`.) Then open <http://localhost:4000>.

Run `just` to see all available recipes (`preview`, `up`, `down`, `build`, `clean`, `new-post`).
